# Personal Portfolio Web Application

A responsive and accessible personal portfolio website developed using HTML5, CSS3, Bootstrap 5, and JavaScript ES6+. The portfolio showcases my education, technical skills, projects, achievements, certifications, and contact information.

## 📌 Project Overview

This project was developed as part of the Full Stack Development course to demonstrate concepts covered in Unit I and Unit II.

The portfolio provides a structured way to present my academic background, technical skills, projects, achievements, and certifications through a responsive and interactive web interface.

## ✨ Features

- Responsive personal portfolio design
- Semantic HTML5 structure
- Responsive Bootstrap navigation bar
- Home / Profile section
- About Me section
- Education section with responsive table
- Skills section with dynamically generated skill badges
- Projects section with dynamically generated project cards
- Achievements and Certifications section
- Contact form with client-side validation
- Email redirection using `mailto:`
- Light / Dark theme toggle
- Smooth scrolling navigation
- Hover effects and transitions
- Mobile-friendly layout
- Accessibility-focused form labels and keyboard focus styles
- Automatically updated footer year
